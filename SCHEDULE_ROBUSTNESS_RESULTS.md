# Agent Update Order Robustness Analysis

## Aim and design

The first resource experiment ran the agents in fixed ID/list order. This analysis
compares the same 120 seed-condition pairs, under the same 2×2 resource conditions,
with an agent order shuffled once per tick. The fixed-order values were taken from
the earlier final experiment; the 120 runs were re-run with shuffled order. Each
seed's last-100-tick mean is the unit of analysis.

The order permutation is generated by a scheduler RNG separate from the decision RNG.
Nevertheless, the decision RNG is shared among agents; when the order changes, which
agent the random decision draws go to can diverge. The same seed labels are paired,
but this is not a full common-random-numbers design.

## Primary resource factorial contrasts

Contrast = high level minus low level. `Δ` is the shuffled-order minus fixed-order
factorial effect difference. The bracketed values are bootstrap 95% intervals
obtained by resampling seed pairs within cells.

| Outcome / contrast | Fixed order | Shuffled order | Δ (95% CI) |
|---|---:|---:|---:|
| Cooperation — capacity | +0.090 | +0.086 | −0.004 [−0.013, +0.004] |
| Cooperation — regeneration | +0.044 | +0.044 | −0.000 [−0.008, +0.008] |
| Cooperation — interaction | +0.023 | +0.020 | −0.003 [−0.020, +0.013] |
| Conflict — capacity | −0.099 | −0.096 | +0.003 [−0.006, +0.012] |
| Conflict — regeneration | −0.043 | −0.045 | −0.002 [−0.011, +0.007] |
| Conflict — interaction | −0.020 | −0.015 | +0.005 [−0.012, +0.023] |
| Scarcity — capacity | −0.560 | −0.527 | +0.033 [−0.025, +0.091] |
| Scarcity — regeneration | −0.249 | −0.269 | −0.019 [−0.077, +0.039] |
| Scarcity — interaction | −0.149 | −0.160 | −0.011 [−0.128, +0.103] |

In this sample all nine Δ intervals cover zero. The directions of the capacity and
regeneration effects are the same in both schedules; the effect sizes are close. This
result does not prove that the update order has no effect: no equivalence bound was
defined, model uncertainty was not measured, and with 30 seeds/cell the detection
power may be limited. The uncertainty is wider especially for the scarcity and
interaction contrasts.

## Cell-level observation

The shuffled-order minus fixed-order differences in the primary outcome means are
small in all four cells. The largest point difference is in scarcity, in the 120
capacity / 0.016 regeneration cell, about +0.051 (95% paired bootstrap interval
−0.019 to +0.118); the between-seed variability is high in this cell. All metric
details of the cells and the seed-level values are in the results JSON and the CSV
files.

## Interpretation

The findings of the first resource experiment appear robust in direction between the
tested **fixed order and the per-tick shuffled order**. The results cannot be
generalized to a different simultaneous/synchronous action semantics, other agent
selection rules, different parameters or human behavior. A next robustness step could
be to separately evaluate a design that separates the decision RNGs per agent or that
pins the same exogenous shocks to agent identities.

## Scope note (2026-10-09)

In the four resource cells of this comparison the agents were well fed (ISSUE-015).
When regeneration is lowered below need, the fixed order produces priority by
identity and changes the results substantially (ISSUE-016). The robustness result
here should not be generalized to scarce regimes.

## Reproduction

- `run_schedule_robustness.py`: produces the 120 shuffled runs and the time series.
- `analyze_schedule_robustness.py`: computes the factorial Δ intervals from the matched cell-seed data.
- `output/schedule_robustness/results.json`: cell differences and the full factorial comparisons.
- `output/schedule_robustness/shuffled_seed_summaries.csv`: 120 seed summaries.
- `output/schedule_robustness/shuffled_timeseries.csv`: 60,000 tick observations.
- Fixed-order matches: `output/resource_factorial/seed_summaries.csv` and `timeseries.csv`.
